# ATM Bank Management System

A Java Swing and MySQL based ATM and Bank Management System developed as a desktop application.

## Features

- New Account Registration
- Automatic 16-digit Card Number Generation
- Automatic 4-digit PIN Generation
- User Login
- Cash Withdrawal
- Cash Deposit
- Fast Cash
- Balance Enquiry
- Mini Statement
- PIN Change
- Transaction History

## Technologies

- Java
- Java Swing / AWT
- MySQL
- JDBC
- Apache NetBeans
- MySQL Connector/J
- JCalendar

## Database Setup

1. Install MySQL Server and MySQL Workbench.
2. Open `database.sql`.
3. Execute the SQL script in MySQL Workbench.
4. The script creates the `bms` database and required tables.
5. Configure your MySQL username and password in `Conn.java`.

## How to Run

1. Open the project in Apache NetBeans.
2. Add MySQL Connector/J and JCalendar libraries.
3. Set your MySQL credentials in `Conn.java`.
4. Clean and Build the project.
5. Run the application.

## Project Purpose

This project demonstrates Java Swing GUI development, JDBC connectivity, MySQL database operations, OOP concepts, and basic banking transaction management.

## Security

This project is for educational purposes. Do not use real banking information, Aadhaar numbers, PAN numbers, or passwords while testing.
